# 852 Technologies website

This repository contains the static website for 852 Technologies and its product pages.

## Project handoffs

Read [PRIVACY_COMPLIANCE.md](PRIVACY_COMPLIANCE.md) before changing the Privacy Notice, analytics, forms, contact links, domains, hosting, tracking, cookies, advertising, or third-party services.

Read [852_Technologies_Branding_Chat_Handoff.md](852_Technologies_Branding_Chat_Handoff.md) before changing branding, logo usage, visual direction, or core messaging.

## Run locally

Install [Node.js](https://nodejs.org/), then run either command from the repository root:

```sh
npm run dev
```

```sh
npm run preview
```

Both commands serve the site at [http://127.0.0.1:4173](http://127.0.0.1:4173). Since this is a static site with no separate build step, the commands use the same lightweight local server.

## Visit counters

The 852 Technologies, Stoored, and eMatch Lite websites use [GoatCounter](https://www.goatcounter.com/) for cookie-free page-view counting. Each site has its own GoatCounter site code, and the homepage displays its page-view count in the footer. GoatCounter's counter script and count API are provided by GoatCounter; the sites do not host the counting service themselves.
